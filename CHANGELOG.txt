[0.3.0] - 2026-09-04 (Текущая версия с UI, CI/CD и документацией)
Добавлено
Графический интерфейс пользователя (GUI) на базе Qt 6.8.0:
Реализован MainWindow с элементами управления:
Кнопки Test Sound, Start/Stop.
Ползунки для настройки громкости, чувствительности и количества подтверждающих кадров.
Блок видеопотока с QGraphicsView для отображения кадров с камеры.
Панель статуса (индикация тревоги, расстояние до кота).
Поддержка стилей для кнопок и ползунков (цвета, радиусы, фон).
Документация:
ARCHITECTURE.md с описанием архитектуры системы.
CLASS_DIAGRAM.puml (диаграмма классов в формате PlantUML).
.clang-format для стандартизации стиля кода.
Тестирование:
Юнит-тесты на базе Google Test (main_test.cpp) для модулей:
AlarmSystem (проверка активации тревоги).
CatDetector (обнаружение кота с высокой уверенностью).
SoundPlayer (плавное нарастание громкости, обработка ошибок).
UDPCommunicator (моки для сетевых команд).
utils (проверка таймеров).
Моки для изоляции тестов (например, MockUDPCommunicator).
CI/CD:
Конфигурация GitHub Actions для автоматической сборки на Linux.
Кроссплатформенная поддержка через CMake:
Условная компиляция для Windows (udp_communicator_win.h/cpp) и Linux (udp_communicator_unix.h/cpp).
Автоматическое обнаружение ОС (#ifdef _WIN32).
Конфигурация:
Поддержка конфигурационного файла config.toml (через библиотеку toml++).
Гибкая настройка путей к моделям YOLO, звуковым файлам и параметрам системы.
Логирование:
Улучшенные сообщения об ошибках в UDPCommunicator (Windows/Linux).
Отладочные выводы в SoundPlayer и AlarmSystem.
Многопоточность:
Отдельные потоки для GUI (qtThread) и обработки UDP-команд (udpThread).
Синхронизация с использованием std::atomic<bool>.
Изменено
Рефакторинг кода:
Разделение монолитного main.cpp на модули:
AlarmSystem (управление тревогой).
CatDetector (обнаружение кота с YOLOv4-tiny).
SoundPlayer (воспроизведение звуков через SFML 3.0).
UDPCommunicator (кроссплатформенная сетевая коммуникация).
utils (вспомогательные функции, например getCurrentTimeMs()).
Улучшена логика AlarmSystem:
Плавное нарастание громкости (currentDynamicVolume) с лимитом до 100%.
Счетчик catFrameCounter для подтверждения обнаружения кота (5 последовательных кадров с уверенностью > 85%).
Удалены моментальные сбросы тревоги при кратковременном исчезновении кота.
Оптимизирована работа с OpenCV DNN:
Использование blobFromImage для предобработки кадров.
Вычисление дистанции до кота (currentDistance) на основе ширины объекта и фокусного расстояния камеры.
Улучшена обработка звуков:
Случайный выбор звукового файла из 5 вариантов (sound1.mp3–sound5.mp3).
Использование PowerShell на Windows и системных команд на Linux для воспроизведения.
Сетевая коммуникация:
Добавлена проверка инициализации сокетов в UDPCommunicator.
Обработка ошибок для Linux (errno, fcntl).
Документация:
Обновлен README.md с описанием функционала и инструкциями по сборке.
Добавлены комментарии в коде (например, в MainWindow).
Удалено
Устаревшие комментарии и дублирующаяся логика.
Зависимость от spdlog (закомментирована, оставлена как перспективная замена std::cout для логирования).

[0.1.0] - 2026-06-20 (Первая модульная версия)
Добавлено
Модульная архитектура:
Разделение кода на отдельные классы:
AlarmSystem (управление тревогой).
CatDetector (обнаружение кота с YOLOv4-tiny).
SoundPlayer (воспроизведение звуков).
UDPCommunicator (сетевая коммуникация).
utils (вспомогательные функции).
Функционал:
Обнаружение кошек с использованием YOLOv4-tiny и OpenCV 4.11.0.
Воспроизведение звуков через SFML 3.0 (плавное нарастание громкости).
Отправка уведомлений на устройства в локальной сети через UDP (команды ALARM_ON/ALARM_OFF).
Поддержка удаленного отключения тревоги (ALARM_OFF).
Инфраструктура:
CMakeLists.txt для сборки проекта.
Добавлен .gitignore для игнорирования служебных файлов (например, build/, *.user).
Документация в README.md и ARCHITECTURE.md.
Изменено
Логика работы AlarmSystem:
Сирена длится 30 секунд, а не тухнет при пропадании кота.
Добавлен внутренний счетчик громкости (currentDynamicVolume) для плавного нарастания звука.
Обработка ошибок:
Улучшена обработка ошибок в UDPCommunicator и SoundPlayer.
Удалены лишние блоки else, которые приводили к моментальному отключению тревоги.
Удалено
Устаревшие комментарии и дублирующаяся логика.
