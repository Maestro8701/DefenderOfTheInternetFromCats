# Архитектура системы "Defender of the Internet from Cats"

## 🔧 Общее описание

Мультиплатформенная система наблюдения с машинным зрением для обнаружения и предотвращения вторжений кошек в помещение.
Использует **ECS-подобный** подход для модульной архитектуры, OpenCV для детекции, SFML для звука, UDP для сетевого взаимодействия.

## 🧩 Основные компоненты и их ответственность

### 1. **CatDetector** (`cat_detector.h`)
- **Задача**: Обнаружение кошек на кадре с помощью YOLOv4-tiny
- **Вход**: Кадр (`cv::Mat`)
- **Выход**: `bool` — найдена ли кошка, и `float` — расстояние до неё
- **Функции**:
  - `detectCat()` — обработка кадра и детекция объектов класса "кошка"
  - Использует OpenCV DNN для инференса
- **Параметры**:
  - `CONFIDENCE_THRESHOLD = 0.85`
  - `FRAME_CONFIRM_COUNT = 2` (нужно подтверждение в 2 кадра)
  - `TRIGGER_DIST = 500` мм (порог расстояния для активации)

> **Примечание**: `classId 15` — это кошка в YOLOv4-tiny (Darknet)

---

### 2. **AlarmSystem** (`alarm_system.h`)
- **Задача**: Управление состоянием тревоги и звуком
- **Статические переменные**:
  - `alarmActive` — флаг активности тревоги
  - `lastSoundTime` — время последнего изменения громкости
  - `alarmStartTime` — время запуска тревоги (для 30-секундной сессии)
  - `ALARM_DURATION_MS = 30000` (30 секунд)
- **Логика**:
  - Если кот обнаружен → запуск тревоги (`playScarySound(0)`)
  - Звук усиливается каждые `soundInterval = 6000 мс` (6 секунд)
  - Сирена длится **30 секунд**, затем автоматически отключается
  - Отправка сообщений `"ALARM_ON"` / `"ALARM_OFF"` через UDP
- **Особенность**: Работает даже если кот временно исчез — тревога не прерывается

---

### 3. **SoundPlayer** (`sound_player.h`)
- **Задача**: Воспроизведение звуков с плавным нарастанием громкости
- **Функции**:
  - `playScarySound(int volumeLevel)` — старт или увеличение громкости
  - `stopSound()` — остановка и сброс громкости
  - `setPathToSounds()` — настройка пути к звукам (по умолчанию: `./multimedia/sound/`)
- **Механизм**:
  - При первом старте: громкость = 15%
  - При каждом вызове `playScarySound()` во время тревоги громкость увеличивается на 5%
  - Максимум: 100%
  - Звук зациклен (`setLooping(true)`)
- **Файлы**: `sound1.mp3` — `sound5.mp3` (звуки: пылесос, змея, собака, ультразвук, пар)

---
### 4. **UDPCommunicator** (`udp_communicator.h`)
- **Задача**: Отправка и приём команд по UDP в локальной сети
- **Параметры**:
  - Порт: `12345`
  - Адрес получателя: `192.168.1.100` (можно изменить)
- **Функции**:
  - `sendMessage()` — отправка сообщений на телефон/пк
  - `checkForCommands()` — приём команд (например, `"ALARM_OFF"`)
  - Автоматическое отключение тревоги при получении команды
- **Сообщения**:
  - `"ALARM_ON"` — тревога включена
  - `"ALARM_OFF"` — тревога отключена (можно отправить с телефона)

---
### 5. **utils.h**
- **Функции**:
  - `getCurrentTimeMs()` — получение текущего времени в миллисекундах (для таймеров)
